Import

Paste rows with this header: date,kind,exitdate,symbol,side,qty,entry,exit,stop,fees,pnl,setup,grade,notes. Dates are YYYY-MM-DD, kind is day or swing, and exitdate is the day a swing was closed. If you leave entry and exit out, put the result in the pnl column.

Sample trades

Five example trades so you can see the calendar working. They're marked "sample" and you can clear them any time.
